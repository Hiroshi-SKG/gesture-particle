# Gesture Particle

カメラに映る片手で、流れる光の粒子を操るインタラクティブアートです。手を開くと光が枝分かれし、速く動かすと粒子が遅れて弧を描きながら合流します。手を握ると白金色のエネルギー球に凝縮し、開くと閃光、衝撃波、火花とともに解放されます。カメラの開始前や手が見えないときも、光が循環しながら形を変えます。

## 使用技術

- HTML5、CSS、JavaScript（ES Modules）
- Three.js **0.170.0** による WebGL 2 描画。時間差と慣性を持つ少数の追従点を基に、粒子ごとの軌道、乱れ、発光をシェーダーで計算します。主粒子はタッチ端末で約 20,000 個、PC で約 50,000 個から始め、フレーム時間に応じて粒子数と描画解像度を段階的に調整します。負荷が下がってから画質を戻すまで長めに待ち、頻繁な変動を抑えます。
- MediaPipe Tasks Vision **0.10.21** の Hand Landmarker と **float16 モデル v1**。指の曲がり具合で開閉を連続的に反映します。映像は画面に表示しません。認識は CPU で実行し、処理頻度を描画と独立して制限します。

## 動作方法

1. このディレクトリで `python3 -m http.server 8000` を実行します。
2. `http://localhost:8000/` を開きます。WebGL 2 対応ブラウザと、ライブラリおよびモデルを取得するためのネット接続が必要です。
3. **カメラを開始**を押してアクセスを許可し、片手をカメラに向けます。停止するときは**カメラを停止**を押します。
4. 権限を拒否した場合はサイト設定でカメラを許可し、再試行します。

iPhone からは HTTPS の公開 URL を Safari で開いてください。ローカルサーバーに LAN 内 IP アドレスの HTTP URL でアクセスした場合、カメラ機能は利用できません。

## GitHub Pages での公開

PR のマージ後、リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、`main` ブランチと `/ (root)` を指定します。公開後は同じ画面に表示される HTTPS の URL を開きます。ビルド、パッケージのインストール、API キーは不要です。

## プライバシー

カメラは開始ボタンを押してから要求します。映像と認識データはブラウザ内で処理し、保存や外部送信は行いません。音声は取得しません。カメラを停止するかページを離れると、映像トラックを解放します。CDN と Google Cloud Storage への通信はライブラリ、WASM、モデルの取得に使います。
